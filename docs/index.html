Sketchbook Glyphs

Original two-tone SVG glyphs for Magic: The Gathering playtest proxies: one per card type, one per subtype, and per-card glyphs for the most-played cards.

Fetch them at a release tag: https://cdn.jsdelivr.net/gh/zbhochhalter/MTG_Glyphs@v0.1.0/manifest.json. Source and contract: github.com/zbhochhalter/MTG_Glyphs.
